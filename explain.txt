Program ini mendemonstrasikan kombinasi function dan class dalam satu sistem donasi sederhana. Function baca_nominal() mengembalikan (return) nilai tanpa parameter, sedangkan tentukan_respon() mengembalikan teks respon berbeda berdasarkan nominal donasi menggunakan percabangan if-elif-else bertingkat. Class Saweria memiliki constructor yang menyimpan riwayat donasi, method tampilkan_menu() sebagai non-return tanpa parameter untuk menampilkan pilihan menu, dan tampilkan_respon() sebagai non-return berparameter untuk menampilkan balasan streamer. Pada program utama, perulangan while menjalankan menu secara terus-menerus hingga pengguna memilih keluar (pilihan 3): pilihan 1 meminta nama dan nominal donasi, memprosesnya melalui kedua function di atas, lalu menyimpannya ke riwayat; sedangkan pilihan 2 menampilkan seluruh riwayat donasi yang telah tercatat.
